# Firebird Match

Приложение помогает подобрать подрядчиков для мероприятий по датасету организаторов Firebird #79-lite (трек 06 «Креативные индустрии», кейс «Умный подбор подрядчиков»). В каталоге 66 анонимизированных и синтетических профилей. Бронирований и отправки заявок нет.

## Как работает

Пользователь → веб форма Streamlit → AI агент → инструмент `recommend_contractors` → детерминированный Python движок `recommend()` → CSV → структурированный результат → AI объяснение → карточки.

**Детерминированный слой:** Python проверяет ввод, город, категорию, календарь занятости, бюджет, формат, язык и длительность. Он выбирает до трёх карточек и всегда сортирует их по начальной цене, затем по ID. Это порядок по цене, не рейтинг качества. Статусы: `MATCHED`, `NO_CATEGORY_IN_CITY`, `NO_MATCH`. Счётчики причин исключения могут пересекаться.

**AI слой:** официальный OpenAI Python SDK с function calling вызывает инструмент и формулирует индивидуальные объяснения по его данным. AI не фильтрует профили, не меняет ID, цены и порядок. При отсутствии ключа или сбое API приложение показывает объяснения по детерминированным правилам с явной пометкой. Текст AI может различаться между запусками, порядок карточек стабилен.

## Установка и запуск (PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:OPENAI_API_KEY = "ваш ключ"  # только для AI объяснений; не сохраняйте в Git
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Ключ можно не задавать: веб форма и подбор работают локально. `.env.example` показывает имя переменной; `.env` исключён из Git. Для CLI и тестов:

```powershell
.\.venv\Scripts\python.exe cli.py --demo
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Рабочий пример: город `Алматы`, дата `2026-09-26`, тип `корпоратив`, категория `Банкетный зал`, бюджет `10000000` ₸. Demo CLI строит примеры A–D из CSV; для E сравнивает две даты одного запроса, где занятость меняет ID.

Для ручной демонстрации на текущем CSV:

| Сценарий | Город | Дата | Формат | Категория | Бюджет ₸ | Ожидаемый исход |
| --- | --- | --- | --- | --- | ---: | --- |
| A: много профилей | Алматы | 2026-09-26 | корпоратив | Банкетный зал | 10000000 | MATCHED, три карточки |
| B: редкая категория в городе | Астана | 2026-09-23 | конференция | Банкетный зал | 10000000 | MATCHED, одна карточка |
| C: категории нет в городе | Зарубежье | 2026-09-26 | корпоратив | Банкетный зал | 1000000 | NO_CATEGORY_IN_CITY |
| D: условия исключают всех | Алматы | 2026-09-26 | корпоратив | Банкетный зал | 1 | NO_MATCH |
| E: дата меняет ID | Астана | 2026-09-23 и 2026-09-24 | свадьба | Видеограф | 6000001 | NO_MATCH → MATCHED из-за календаря |

## Ограничения данных

Календарь покрывает только 2026-09-23—2026-12-31. Если дата отсутствует в `busy_dates`, это означает лишь «по календарю датасета не занят», не подтверждённую бронь. Цена указана «от» и не является окончательной сметой. В карточке помечены синтетические профили и оценочные город или цена. Описания — утверждения самого профиля, а не проверенные системой факты. API не используется для фактической фильтрации.
