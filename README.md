# Firebird Match

Локальное ядро для кейса Firebird #79-lite «Умный подбор подрядчиков» (трек 06 «Креативные индустрии»). Использует CSV датасет организаторов Firebird #79-lite. Не бронирует подрядчиков, не отправляет заявки и не связывается с ними.

## Запуск

Нужен Python 3; внешние зависимости и API key не нужны.

```powershell
python cli.py --city Алматы --date 2026-10-10 --event-format свадьба --category Фотограф --budget-kzt 1000000
python cli.py --demo
python -m unittest discover -s tests -v
```

Для необязательных условий можно передать `--hours 4` и `--language русский`. CSV по умолчанию берётся рядом с `cli.py`; другой файл задаётся через `--csv PATH`.

## Логика

Вход проверяется до подбора. Доступный календарь ограничен датами с 2026-09-23 по 2026-12-31 включительно; вне диапазона выводится «Для этой даты нет данных о занятости». Подрядчик проходит только при совпадении города, категории, формата и (если задан) языка, свободной дате по `busy_dates`, цене не выше бюджета и длительности не выше `max_hours` (если она заполнена). Пустой `max_hours` означает, что фильтр длительности к профилю неприменим. Занятость площадок проверяется так же, как у остальных профилей.

Результаты сортируются по начальной цене по возрастанию, затем по `id`; это предварительный порядок по цене, а не рейтинг качества. Возвращается не более трёх профилей. Если их меньше трёх, CLI сообщает число подходящих профилей либо малый размер каталога этой категории в городе. Счётчики причин исключения могут пересекаться и не суммируются как число людей.

Бизнес-исходы: `MATCHED` — есть подходящие профили; `NO_CATEGORY_IN_CITY` — в городе нет профиля категории; `NO_MATCH` — категория есть, но остальные фильтры никого не пропустили. Некорректный ввод возвращает понятную ошибку отдельно.

Цена — «от» и не является сметой. Отсутствие даты в календаре датасета означает только «по календарю датасета не занят», не подтверждённую бронь. В карточках показаны исходные признаки синтетического профиля и оценочных города/цены. Синтетические профили помечены «Синтетический профиль из датасета организаторов», прочие — «Анонимизированный профиль».

## Текущий статус и ограничения

Реализованы импорт и проверка CSV, детерминированная фильтрация, объяснения и CLI с demo на реальном датасете. AI-интеграция и веб-интерфейс ещё не реализованы. Календарь проверен только для диапазона 2026-09-23—2026-12-31. Датасет содержит анонимизированные и синтетические записи, а некоторые цены и города помечены оценочными; результат не заменяет подтверждение у подрядчика.
