# Firebird Match

## Проблема

У заказчика уже есть каталог подрядчиков своего города. Нужно выбрать из него до трёх профилей для конкретного мероприятия и объяснить выбор, а не расширять список.

## Решение

Firebird Match проверяет запрос по каталогу Firebird #79-lite и показывает до трёх карточек подрядчиков с объяснениями. Приложение не бронирует услуги и не отправляет заявки.

## Основной сценарий

Input (город, дата, формат, категория, бюджет; необязательные язык и длительность) → deterministic filtering → 0–3 profiles → optional AI evidence selection → cards.

## Что реализовано

- Каталог из 66 профилей, проверка ввода и строгие фильтры по городу, категории, календарю занятости, бюджету, формату, языку и длительности.
- Стабильная сортировка по начальной цене и ID, вывод не более трёх профилей.
- Streamlit интерфейс, CLI, сценарии A–F, unit tests и Streamlit AppTest.
- Необязательный AI выбор выдержки из уже отобранного профиля с проверкой ID и принадлежности выдержки; локальный fallback.

## Архитектура

```text
User
  ↓
Streamlit
  ↓
run_matching
  ↓
recommend_contractors tool
  ↓
catalog.recommend
  ↓
contractors.csv
  ↓
ordered candidates
  ↓
evidence selection (AI или локальные объяснения)
  ↓
cards
```

`run_matching` вызывает Python инструмент `recommend_contractors`, который использует `catalog.recommend`. При доступном API AI работает только с уже возвращёнными кандидатами. Python проверяет ответ AI перед показом.

## Почему Python и AI разделены

**Python** контролирует hard constraints: доступность по календарю, бюджет, формат, язык, длительность, ID и порядок. **AI** выбирает релевантную выдержку (`evidence_id`) внутри уже выбранного профиля. AI не выбирает подрядчиков, не меняет порядок, цены или факты. Описания профилей считаются данными, а не инструкциями.

## Technologies

- Python 3.10 или новее (проверено на Python 3.14; нужны `venv` и `pip`).
- Streamlit `1.64.0` — веб-интерфейс и AppTest.
- OpenAI Python SDK `3.19.0` — необязательный AI выбор выдержок.
- `unittest` из стандартной библиотеки — тесты.

`requirements.txt` содержит только две прямые runtime зависимости: `streamlit` и `openai`.

## Dataset

`contractors.csv` содержит 66 анонимизированных и синтетических профилей из конкурсного датасета. Календарь ограничен периодом **2026-09-23 — 2026-12-31**.

- `synthetic`: синтетический профиль.
- `city_imputed`: город заполнен оценочно; уточните его перед заказом.
- `price_imputed`: начальная цена заполнена оценочно; уточните её перед заказом.

Эти признаки показываются на карточках.

## Installation

Нужны Git и Python 3.10 или новее с `venv` и `pip`. В PowerShell выполните:

```powershell
git clone https://github.com/BAITC-Hacks/hack-4cfb0407-space-bell-studio.git
cd hack-4cfb0407-space-bell-studio
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Активировать виртуальное окружение не требуется. `.env.example` показывает только имя переменной; `.env` автоматически не загружается.

## Run Web

Из папки проекта:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

Откройте URL, выведенный Streamlit (обычно `http://127.0.0.1:8501`). Остановите сервер через `Ctrl+C`. Без ключа работает детерминированный подбор с локальными объяснениями (fallback mode). С действительным ключом возможно получение live AI explanations, основанных на выдержках из профилей; доступность live API проверяется отдельно.

## API key

Для необязательного AI режима нужна переменная окружения текущего процесса `OPENAI_API_KEY`. Не публикуйте ключ в исходниках, README, тестах или Git. Без ключа можно проверить подбор, CLI, интерфейс и тесты. Для локального скрытого ввода ключа в интерактивном терминале есть `run_local.py --web --ask-key`; для офлайн проверки эта опция не нужна. `run_local.py --check-ai --ask-key` выполняет один реальный запрос и возвращает ненулевой код при fallback. По умолчанию запрашивается `gpt-4.1-mini`; `OPENAI_MODEL` позволяет изменить модель. В ручной проверке live AI вернулся локальный fallback с безопасным кодом `AUTH_ERROR` (1 API вызов, 0 tool calls); успешный live AI не подтверждён.

## Demo scenarios

В веб-форме оставьте необязательные язык и длительность не заданными. Выберите значения ниже и нажмите «Подобрать подрядчиков». Результат вычисляется из CSV, а не задан в сценарии заранее.

| Сценарий | Город | Дата | Формат | Категория | Бюджет, ₸ | Ожидаемый business outcome |
| --- | --- | --- | --- | --- | ---: | --- |
| A — dense | Алматы | 2026-09-26 | корпоратив | Банкетный зал | 10000000 | Несколько подходящих профилей; показаны не более трёх в стабильном порядке. |
| B — rare | Алматы | 2026-09-23 | конференция | Флорист | 10000000 | Мало подходящих профилей; показаны размер категории и причины исключения. |
| C — NO_CATEGORY_IN_CITY | Зарубежье | 2026-09-26 | корпоратив | Банкетный зал | 1000000 | В городе нет профиля этой категории. |
| D — NO_MATCH | Алматы | 2026-09-26 | корпоратив | Банкетный зал | 1 | Категория есть, но все профили исключены условиями. |
| E — same query / different date | Алматы | 2026-09-23, затем 2026-09-26 | день рождения | Банкетный зал | 10000000 | Состав подходящих профилей меняется из-за календаря занятости. |
| F — Plan B | Алматы | 2026-09-26 | день рождения | Банкетный зал | 2000000 | `NO_MATCH`; План Б: 2026-09-28 даёт 1 профиль, а на исходную дату первый вариант появляется при начальной цене «от» 2500000 ₸. |

## Three outcomes

- `MATCHED` — есть подходящие профили; показано до трёх.
- `NO_CATEGORY_IN_CITY` — в каталоге выбранного города нет профиля категории.
- `NO_MATCH` — категория есть, но все профили исключены условиями.

При малом числе карточек показаны размер категории и причины исключения. Счётчики причин могут пересекаться.

## Plan B

После `NO_MATCH` приложение отдельно ищет, поможет ли изменение только даты или только бюджета. Исходный запрос и его нулевой результат остаются прежними; пользователь сам выбирает новые условия и запускает подбор заново. Для `MATCHED` и `NO_CATEGORY_IN_CITY` План Б не показывается.

- Ближайшая дата ищется в календаре 2026-09-23 — 2026-12-31 в порядке `+1 день, −1 день, +2, −2…`. При равном расстоянии сначала выбирается будущая дата. Город, категория, формат, бюджет, язык и длительность сохраняются.
- Минимальный бюджет — наименьшая начальная цена «от», при которой профиль проходит тот же подбор на исходную дату. Город, дата, категория, формат, язык и длительность сохраняются; занятые и неподходящие профили не учитываются.
- Обе проверки выполняет Python через `catalog.recommend()` по тому же CSV. Предложение не гарантирует бронь или окончательную цену.

## Determinism

Python определяет допустимые ID и порядок по начальной цене и ID. AI prose не служит источником порядка, не меняет фильтры и не выбирает новых подрядчиков. При отсутствии ключа или некорректном ответе AI используется детерминированный fallback.

## Limitations

- Цена указана «от» и не является итоговой сметой.
- Свободная дата означает только отсутствие записи о занятости в календаре датасета; бронирование не подтверждено.
- Рекламные заявления принадлежат профилю и не проверены независимо.
- Календарь ограничен периодом 2026-09-23 — 2026-12-31.
- AI требует действительный API ключ и доступ к модели; fallback детерминированный.

## How jury can verify

1. Клонируйте репозиторий командами из **Installation**.
2. Создайте `.venv` и установите зависимости из `requirements.txt`.
3. Запустите **Tests** и проверьте, что тесты проходят.
4. Запустите **Run Web** без ключа и откройте показанный URL.
5. Введите сценарий **A**: появятся до трёх карточек.
6. Введите сценарий **B**: проверьте малое число карточек и причины исключения.
7. Введите сценарий **C**: проверьте отсутствие категории в городе.
8. Введите сценарий **D**: проверьте отсутствие подходящих при существующей категории.
9. Введите сценарий **E** дважды с разными датами: сравните карточки.
10. Введите сценарий **F**: исходный результат остаётся пустым, а План Б предлагает дату и минимальную начальную цену. Те же случаи доступны через `cli.py --demo`.
11. При наличии собственного разрешённого ключа отдельно проверьте необязательный AI режим; ключ для шагов 1–10 не нужен.
